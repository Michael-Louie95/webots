 PASO 1: INSTALAR DEPENDENCIAS

Abre PowerShell como ADMINISTRADOR y ejecuta:

Espera a que termine (~2-3 minutos).

 PASO 2: VALIDAR DATASET (IMPORTANTE)

Antes de entrenar, valida que TODO esté correcto:

    cd D:\proyectro_webots
    python validar_dataset.py

Deberías ver:
    ✓ ESTRUCTURA OK
    ✓ YAML OK
    ✓ IMAGENES Y ANOTACIONES OK
    ✓ DATASET LISTO PARA ENTRENAR

Si hay ❌ ERRORES, revisa antes de continuar.


═══════════════════════════════════════════════════════════════════════════════
 PASO 3: ENTRENAR MODELO (ESTO ES LO IMPORTANTE)
═══════════════════════════════════════════════════════════════════════════════

Ejecuta:

    python train_yolo.py

QUE ESPERAR:
  - Se descargan ~22MB del modelo base YOLOv8s (primera vez)
  - Comienza el entrenamiento (100 epochs = 5-15 minutos dependiendo de GPU)
  - Muestra progreso en cada epoch
  - Guarda checkpoints automáticamente
  - Al final, el mejor modelo se guarda en: runs/detect/train_dataset/weights/best.pt

ESTRUCTURA DE SALIDA:
    runs/detect/train_dataset/
    ├── weights/
    │   ├── best.pt        ← ESTE ES TU MODELO FINAL
    │   └── last.pt
    ├── results.csv        (métricas por epoch)
    ├── confusion_matrix.png
    └── ...


═══════════════════════════════════════════════════════════════════════════════
 PASO 4: EVALUAR MODELO EN DATASET DE VALIDACION
═══════════════════════════════════════════════════════════════════════════════

Después de entrenar:

    python evaluar_modelo.py

VER:
  - mAP@0.5: es tu métrica principal (meta: >85%)
  - Precisión: cuántos falsos positivos
  - Recall: cuántos objetos detecta
  - Confusion Matrix: qué clases confunde

INTERPRETAR:
  - mAP@0.5 > 0.85  →  ✅ EXCELENTE (supera meta de tesis)
  - mAP@0.5 > 0.70  →  ✓ BUENO
  - mAP@0.5 < 0.60  →  ⚠️ NECESITA MEJORA

═══════════════════════════════════════════════════════════════════════════════
 HIPERPARAMETROS (SI NECESITAS AJUSTAR)
═══════════════════════════════════════════════════════════════════════════════

Abre train_yolo.py y ajusta estas variables:

EPOCHS = 100           # Aumenta si underfitting, baja si overfitting
BATCH = 16             # Baja si tienes RAM limitada (8, 12)
IMGSZ = 640           # Tamaño de entrada (640x640 es estándar)
PATIENCE = 20         # Early stopping si no mejora en N epochs

Para MEJOR PRECISION (si mAP<0.85):
  1. Aumenta EPOCHS a 150
  2. Baja BATCH a 8 (entrena más lento pero más preciso)
  3. Agrega más datos (más imágenes de Webots)


═══════════════════════════════════════════════════════════════════════════════
 SI ALGO FALLA
═══════════════════════════════════════════════════════════════════════════════

ERROR: "CUDA not available"
  → No tienes GPU NVIDIA. Entrena en CPU (más lento)
  → Cambia: DEVICE = 'cpu' en train_yolo.py

ERROR: "No module named 'ultralytics'"
  → pip install ultralytics (verifica que esté instalado)

ERROR: "data.yaml not found"
  → Verifica que exists: D:\proyectro_webots\dataset_yolo\data.yaml

ERROR: "Out of memory"
  → Baja BATCH (16 → 8 → 4)
  → Baja IMGSZ (640 → 416)

ERROR: "No detections"
  → Dataset puede tener problemas
  → Ejecuta: python validar_dataset.py
  → Verifica que cada imagen tiene un .txt con anotaciones

 TIPS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

✅ Los datos sintéticos de Webots son PERFECTOS
   - Sin ruido
   - Sin oclusiones reales

   1. Agrega más datos (toma más fotos con el dron)
   2. Aumenta epochs a 150
   3. Usa YOLOv8m en lugar de v8s

⚠️ Si mAP > 0.90 pero overfitting:
   1. Baja epochs
   2. Reduce patience
   3. Aumenta augmentation
